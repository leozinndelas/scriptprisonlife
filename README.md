## ✨ Features

### ⚡ Main (Dashboard)
| Feature | Descrição |
|---------|-----------|
| 🚪 Remover Portas | Remove todas as portas e grades da prisão |
| 🔫 Pegar Armas | Coleta todas as armas disponíveis no mapa |
| 💥 Destruir Cercas | Remove todas as cercas do mapa |
| 🔓 Pegar Keycard | Obtém keycard para abrir portas |

### 🏃 Movement
| Feature | Descrição |
|---------|-----------|
| Speed Hack | Velocidade customizável (16-200) |
| Jump Power | Força do pulo customizável (50-300) |
| Noclip | Atravessa paredes e objetos |
| Fly | Voa pelo mapa com WASD + Space/Shift |
| Infinite Jump | Pula infinitamente no ar |

### ⚔️ Combat
| Feature | Descrição |
|---------|-----------|
| Kill Aura | Ataca jogadores próximos automaticamente |
| No Recoil | Remove recuo das armas |
| Auto Arrest | Prende jogadores próximos (como policial) |
| Anti Arrest | Evita ser preso |
| Punch Aura | Soca todos os jogadores próximos |

### 🌀 Teleport
| Feature | Descrição |

| 👮 Base da Polícia | Teleporta para a delegacia |
| 🏢 Prisão (Spawn) | Teleporta para o spawn da prisão |
| 🌳 Pátio | Teleporta para o pátio |
| 🏰 Torre de Guarda | Teleporta para a torre |
| 🚗 Estacionamento | Teleporta para o estacionamento |
| 🚁 Helicóptero | Teleporta para o helicóptero |
| 🏥 Enfermaria | Teleporta para a enfermaria |
| 🔫 Armeiro | Teleporta para a sala de armas |
| 🍔 Cafeteria | Teleporta para a cafeteria |
| 🎯 TP Jogador Próximo | Teleporta para o jogador mais perto |
| 🔀 TP Random | Teleporta para um jogador aleatório |

### 👁️ Visuals

## ⌨️ Keybinds

| Tecla | Função |
|-------|--------|
| `RightCtrl` | Toggle UI (Abrir/Fechar) |
| `N` | Toggle Noclip *(quando ativado)* |
| `F` | Toggle Fly *(quando ativado)* |
| `Space` (no ar) | Infinite Jump *(quando ativado)* |

## 🎨 Design

- **Tema:** Dark Glassmorphism com acentos Neon (Roxo/Azul)
- **UI:** Sidebar com tabs + área de conteúdo scrollável
- **Animações:** Tweens suaves em todos os elementos interativos
- **Componentes:** Toggles com switch animado, sliders com gradiente, botões com hover effects
- **Watermark:** Pulsante com efeito de glow sutil
